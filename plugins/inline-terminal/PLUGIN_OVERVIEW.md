Run the commands an agent suggests without copying them anywhere.

## What you get

- A **Run** button under every `bash`, `sh`, `shell`, `zsh`, `console`,
  `shell-session` and `terminal` code block in agent replies.
- A live, interactive terminal right under the block: answer prompts, type
  passwords, press Ctrl-C, run follow-ups.
- **Panel** moves the same session into bb's terminal panel; **Close** ends it.

## How it works

The shell starts in the thread's workspace on the thread's host, like a
terminal you open from the panel. Nothing runs until you click Run.
